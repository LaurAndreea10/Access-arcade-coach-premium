## 📌 About the Project

**Access Arcade Coach Premium** is a concept-driven front-end app designed for users who benefit from **clarity**, **predictable interaction**, **personalization**, and **reduced cognitive overload**. The project is explicitly framed as a flagship accessible app with a dashboard, onboarding, workspace tabs, local coach, quiz, accessibility profiles, and RO/EN support. :contentReference[oaicite:2]{index=2}

According to the included case study, the core problem is that many educational or productivity apps ignore real user needs around **orientation**, **controlled pacing**, and **practical accessibility**, focusing more on feature volume than on usable structure. The project responds by building an accessible hub that unifies routine, study, local coaching, and calm feedback. :contentReference[oaicite:3]{index=3}

This project combines:

- ♿ practical accessibility
- 🎮 soft gamification
- 🧠 educational flow
- 💬 local coaching
- 📱 mobile-first interface design
- 🌍 bilingual interaction

## 🖥️ Core Modules

### 1. Dashboard
The homepage/dashboard presents a quick overview of progress through metrics such as **XP**, **streak**, **completed missions**, and **quiz score**, alongside a “quick panel” and a **focus timer**. :contentReference[oaicite:17]{index=17}

### 2. Accessibility Profiles
The app includes predefined accessibility presets such as:

- **Calm & Clear**
- **Focus Boost**
- **Reduced Motion** :contentReference[oaicite:18]{index=18}

These profiles are designed for quick activation and can then be refined further inside the **Accessibility Center**. :contentReference[oaicite:19]{index=19}

### 3. Tabbed Workspace
The main workspace is organized into tabs:

- **Task board**
- **Paths**
- **Coach**
- **Analytics**
- **Mandala**
- **Scratch Lab** :contentReference[oaicite:20]{index=20}

The case study explicitly says tabbed organization was chosen to reduce clutter and make orientation clearer. :contentReference[oaicite:21]{index=21}

### 4. Local Coach
The **Coach Local** module is described as fast, **rule-based**, calm, and oriented toward user autonomy, with predictable responses and a clear next step. :contentReference[oaicite:22]{index=22}

### 5. Extended Quiz
The quiz is presented as a **5-question** educational flow with visible progress, short questions, explained feedback, and a calmer reward system. :contentReference[oaicite:23]{index=23}

### 6. Badge Logic
Badges such as **Starter**, **Focus Pilot**, **Quiz Learner**, and **Adaptive Master** reinforce progress through soft motivation rather than punishment-heavy design. :contentReference[oaicite:24]{index=24}

### 7. Mandala Calm
The **Mandala Calm** module is described as a regulation and focus tool based on **slow movement**, **symmetry**, and **simple color choice**, intended as a therapeutic/cognitive micro-break rather than a competitive mini-game. :contentReference[oaicite:25]{index=25}

### 8. Scratch Lab
The **Scratch Lab** extends the product from routine and study into expressive creativity. It is inspired by **block-based logic** and allows users to build simple flows with blocks like **start**, **move**, **say**, and **celebrate**, plus generate story/dialog prompts. :contentReference[oaicite:26]{index=26}

## ♿ Accessibility Approach

The case study and app content clearly frame accessibility as a practical core of the project, not a decorative add-on. Included a11y decisions include:

- **RO / EN support**
- **dark / light / high contrast**
- **font resize**
- **reduced motion**
- **local persistence**
- centralized settings via an **Accessibility Center** :contentReference[oaicite:27]{index=27}

The app also includes a **skip link**, predictable structure, large CTAs, and a focus on calm, understandable UI flows. :contentReference[oaicite:28]{index=28}

## 🧠 UX Direction

The case study highlights several explicit UX decisions:

- a **tabbed workspace** to reduce overload
- **large CTAs** and clear hierarchy
